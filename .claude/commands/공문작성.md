## 작성 전 필수 단계

1. **기획 먼저**: 원본을 그대로 옮기지 말고, 공문에 적합하게 재구성하세요
2. **대상 파악**: 내부문서 vs 고객공지문 구분하세요
3. **구조 설계**: 섹션 순서, 강조점, 정보 박스 배치를 먼저 기획하세요
4. **톤 점검**: 부적절한 표현을 사전에 제거하세요

## 고객 공지문 규칙

### 기본 구조
```
[제목] 고 객 공 지 문 (가운데, 글자 사이 띄어쓰기)

[문서정보 - 우측 정렬, 회색]
문서번호: DF717-CUS-YYYY-NNN
발송일자: YYYY년 MM월 DD일

[인사말]
안녕하세요, DF717입니다.
평소 저희 서비스를 이용해 주시는 고객님께 진심으로 감사드립니다.
아래와 같이 [목적]을 안내드립니다.

[본문]
1. 섹션 제목 (파란색 #1F4E79)
   설명 문장 (박스 상단 배치)
   [정보 박스 - 배경 #E8F4FD]
   • 항목: 내용
      ※ 참고사항 (회색, 들여쓰기, 작은 폰트)

[마무리]
감사합니다.

[서명 - 우측]
DF717 드림
```

### 절대 금지
- 상단 DF717 헤더 넣지 마세요
- ". 끝." 사용하지 마세요
- 이모지/특수기호(★♥) 사용하지 마세요
- 내부 지시사항 포함하지 마세요 (예: "CM분들은 공지해주세요")
- "부탁드립니다" 대신 → "권장", "안내드립니다" 사용하세요

### 레이아웃
- 페이지 여백: 상하 2cm, 좌우 2.54cm
- 표 셀 여백: 0.05cm
- 목표: 1페이지 내 완결

### 박스 내 참고사항 형식
```
※ 참고 내용 (회색 #666666, 들여쓰기, 10pt)
```

- "End." 사용하지 마세요

## 작성 완료 후 체크리스트

고객 공지문 작성 후 반드시 확인하세요:

- [ ] 상단 DF717 헤더 없음
- [ ] ". 끝." 없음
- [ ] 이모지/특수기호 없음
- [ ] 내부 지시사항 없음
- [ ] "부탁드립니다" → 공식 표현으로 변환됨
- [ ] 참고사항: ※ + 회색 + 들여쓰기 적용됨
- [ ] 1페이지 내 완결됨
- [ ] 박스 상단에 설명 문장 배치됨

영문 버전 추가 확인:
- [ ] "End." 없음
- [ ] 한글 버전과 내용 일치
