# DF717 공문 작성 가이드

이 저장소는 DF717의 공식 문서(공문, 고객공지문) 작성을 위한 가이드와 Claude Code 커스텀 명령어를 포함합니다.

## 📁 파일 구조

- `DF717_공문작성_가이드.md` - 상세한 공문 작성 가이드 (참고용)
- `.claude/commands/공문작성.md` - Claude Code 커스텀 명령어

## 🚀 사용 방법

### 1. Claude Code에서 직접 사용

Claude Code에서 공문이나 고객공지문 작성을 요청하면, 자동으로 가이드에 따라 작성됩니다.

```
예: "고객 공지문을 작성해줘"
```

### 2. 커스텀 명령어 사용

`.claude/commands/공문작성.md` 파일이 있는 경우, 다음 명령어로 실행할 수 있습니다:

```
/공문작성
```

## 📋 주요 규칙

### 고객 공지문
- 상단 헤더 없이 깔끔하게
- ". 끝." 사용 안 함
- 이모지/특수기호 금지
- "부탁드립니다" → "권장", "안내드립니다"

### 내부 공문
- "DF717 내부문서 (대외비)" 헤더 사용
- ". 끝." 사용 가능
- 회의록 형식 준수

## 📝 문서 유형

1. **고객 공지문** - 외부 고객 대상
2. **내부 공문** - 임원진 회의록, 내부 정책 문서
3. **영문 문서** - Customer Notice, Operational Update
